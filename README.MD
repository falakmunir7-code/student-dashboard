# 🎓 Student Performance Dashboard

An interactive web-based dashboard that allows users to view student performance using dynamic charts.

## 🚀 Features
- Input-based student selection (A, B, C)
- Dynamic bar chart visualization
- Clean and responsive UI
- Easy navigation between home and dashboard

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Chart.js

## ▶️ How to Run
1. Download or clone the project  
2. Open `index.html` in a browser  
3. Enter a student ID (A, B, or C)  
4. View the performance dashboard
